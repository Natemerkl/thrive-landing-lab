
# End User Manual - Merkl.dev Platform

## Introduction

Welcome to Merkl.dev! This manual will guide you through using our web development platform to order, track, and manage your web development projects.

## Getting Started

### 1. Account Registration

1. Visit the Merkl.dev homepage
2. Click "Get Started" or "Sign Up"
3. Fill in your details:
   - Full name
   - Email address
   - Secure password
4. Check your email for verification (if enabled)
5. Log in to access your dashboard

### 2. Dashboard Overview

After logging in, you'll see your main dashboard with:
- **My Projects**: Active and completed projects
- **Project Selection**: Browse available packages
- **Account Settings**: Manage your profile

## Ordering a Project

### Step 1: Choose Your Package

Navigate to the project selection page where you can choose from:

- **Starter Package** (ETB 12,500)
  - Responsive Landing Page
  - Contact Form Integration
  - Basic SEO Optimization
  - Professional Design Template

- **Business Package** (ETB 25,000)
  - Multi-page Website
  - Content Management System
  - Advanced SEO Optimization
  - Lead Generation Forms
  - Business Branding Integration
  - Social Media Integration

- **Enterprise Package** (ETB 50,000)
  - Custom Web Application
  - Database Design & Integration
  - User Authentication System
  - Admin Dashboard
  - API Development
  - Advanced Security Features
  - Performance Optimization

### Step 2: Customize Your Features

- Review included features for your chosen package
- Add additional features if needed
- Each feature shows its price and description
- Your total will update automatically

### Step 3: Payment Process

1. Review your order summary
2. Choose your payment method:
   - Bank Transfer (Ethiopian banks supported)
   - Mobile Banking
3. Follow the payment instructions provided
4. Upload your payment receipt
5. Submit for verification

## Project Tracking

### Project Status Levels

- **Pending**: Your project is in queue
- **Started**: Initial work has begun
- **In Progress**: Active development
- **Completed**: Project delivered
- **Cancelled**: Project cancelled

### Tracking Your Project

1. Go to "My Projects" section
2. View project progress bar
3. Check status updates and notes
4. See estimated completion dates
5. Download deliverables when completed

### Project Information

Each project shows:
- **Project Title**: Your project name
- **Package Type**: Starter, Business, or Enterprise
- **Total Amount**: Final project cost
- **Features List**: All included services
- **Timeline**: Start and completion dates
- **Status Messages**: Current progress updates

3. **Upload Receipt**: Photograph/scan your receipt
4. **Verification**: Our team verifies within 24 hours
5. **Confirmation**: Project starts after verification

## Frequently Asked Questions

### How long does project development take?

- **Starter Package**: 3-5 business days
- **Business Package**: 1-2 weeks
- **Enterprise Package**: 2-4 weeks

### Can I modify my order after payment?

Minor changes are possible during development. Major changes may require additional payment.

### What if I'm not satisfied?

We offer revisions during development. Final approval is required before project completion.

### Do you provide hosting?

We deliver the website files. Hosting and domain setup can be arranged separately.

### Can I get ongoing maintenance?

Yes, maintenance packages are available separately. Contact us for details.
