
# Admin User Manual - Merkl.dev Platform

## Introduction

This manual covers all administrative functions of the Merkl.dev platform. Admin users have complete control over projects, users, payments, and system settings.

## Admin Access

### Logging In

1. Access the platform with admin credentials
2. Admin dashboard will automatically load
3. Admin-only sections are visible in navigation

### Admin Dashboard Overview

The admin dashboard provides four main sections:
- **Overview**: System statistics and summaries
- **Users**: User management and roles
- **Messages**: Contact inquiries and communication
- **Payments**: Payment verification and management

## User Management

### User Overview

View comprehensive user information:
- Total registered users
- User growth metrics
- Role distribution (admin vs regular users)
- Recent registrations

### Managing User Roles

**Viewing User Roles:**
1. Navigate to Users tab
2. View current role assignments
3. See user registration dates
4. Check user activity status

**Changing User Roles:**
1. Locate user in the users list
2. Click on role dropdown
3. Select new role (admin/user)
4. Changes apply immediately

**User Information Displayed:**
- User ID and email
- Registration date
- Current role
- Last activity
- Project count

## Project Management

### Project Overview

**Project Statistics:**
- Total projects count
- Projects by status
- Revenue from completed projects
- Average project value

### Managing Individual Projects

**Project Information:**
- Project title and description
- Client information
- Payment details
- Feature breakdown
- Timeline information

**Updating Project Status:**
1. Locate project in list
2. Click on status dropdown
3. Select new status:
   - Pending
   - Started
   - In Progress
   - Completed
   - Cancelled
4. Add notes if necessary
5. Save changes

**Project Status Meanings:**
- **Pending**: Awaiting start, payment verified
- **Started**: Initial work begun, planning phase
- **In Progress**: Active development
- **Completed**: Project delivered to client
- **Cancelled**: Project terminated

### Project Features Management

**Viewing Project Features:**
- See all selected features per project
- View custom pricing adjustments
- Check feature categories and descriptions
- Monitor feature totals

**Feature Information:**
- Feature name and description
- Base price vs custom price
- Feature category
- Quantity selected

## Payment Management

### Payment Overview

**Payment Statistics:**
- Total revenue
- Payments by status
- Popular payment methods
- Monthly revenue trends

### Payment Verification

**Verifying Payments:**
1. Navigate to Payments tab
2. Find pending payments
3. Review payment details:
   - Amount and currency
   - Bank and reference number
   - Receipt URL (if uploaded)
   - Payer information
4. Verify against bank records
5. Update payment status
6. Create associated project

**Payment Statuses:**
- **Pending**: Awaiting verification
- **Verified**: Payment confirmed
- **Failed**: Payment unsuccessful
- **Refunded**: Payment returned

### Payment Details

**Information Available:**
- Payment amount and currency
- Bank name and reference
- Payer email and details
- Package type selected
- Payment method used
- Receipt documentation
- Verification notes
